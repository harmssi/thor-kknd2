# UI bits (openkrush_gen2)

All images in this folder are original work made for KKND2 Thor, drawn from code:
`thor/gen_uibits.py` (dialog, logo, loadscreen/splashscreen, sidebar sheets, shroud/fog, beacon, palette, production font)
and `thor/make_glyphs.py` (glyphs.png). No game artwork was copied or traced.
